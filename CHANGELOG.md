# Changelog

Все заметные изменения проекта.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии соответствуют тегам и релизам GitHub.

## [0.2.1] — 2026-10-22

### Добавлено
- Установка и автообновления через Scoop: личный бакет
  [`Rocaccel/scoop-bucket`](https://github.com/Rocaccel/scoop-bucket),
  манифест обновляется GitHub Action после каждого релиза

### Исправлено
- `config.toml` ищется рядом с exe, а не в рабочей директории запуска
  (запуск через шим Scoop или из терминала больше не путает конфиг)

## [0.2.0] — 2026-10-22

### Добавлено
- Перезагрузка `config.toml` на лету: правки кнопок подхватываются без
  перезапуска программы; при смене `port`/`baud` выводится сообщение
  с просьбой перезапустить приложение
- Режим отладки: вместо множества окон — одно окно, показывающее
  последний нажатый код в реальном времени; закрытие окна выключает режим
- Пункт «Версия» в меню трея (версия собирается через ldflags)

### Изменено
- README.md и README.en.md освежены (переписаны по re0)
- config.toml: обновлены комментарии и справочник команд (бинды кнопок не менялись)
- Новая иконка приложения и трея: силуэт пульта с красным диодом
  на тёмной плите
- Окно выключения закрывается при отмене (раньше оставалось висеть)
- README: уточнено описание дебаунса — под ним все действия,
  кроме движения мыши
- Скетч Arduino: печатаются только поддерживаемые протоколы (NEC/RC5)
- Рефакторинг: состояние мыши инкапсулировано в структуру, ускорение
  вынесено в константы, перезагрузка конфига без горутины-воркера
- AGENTS.md: секция прошивки под arduino-cli, пути без имени пользователя

### Удалено
- Исходник иконок `for-icons.png` (в репозитории остаётся готовый `icon.ico`)

## [0.1.0] — 2026-10-21

### Добавлено
- Единый скетч `IR-controler-dual.ino` с автоопределением протокола пульта
  (NEC/RC5) — один скетч подходит для большинства пультов
- Префиксы кодов кнопок в config: `NEC_xx` / `RC5_xx`
  (оба пульта работают одновременно)
- Английская версия README — `README.en.md`
- Раздача exe через GitHub Releases

### Изменено
- README полностью переписан (русская версия)
- `config.toml`: набор кодов `RC5_*` и пример `NEC_2`

### Удалено
- Однопротокольные скетчи `IR-controler-nec.ino` и `IR-controler-rc5.ino`
- Библиотека NecDecoder

## [0.0.5] — 2026-09-14

Первая версия.

- Управление ПК ИК-пультом через Arduino (COM-порт, 115200)
- Эмуляция клавиатуры
- «Умная» мышь с ускорением
- Выключение ПК с 10-секундным таймером отмены
- Работа в системном трее
- Раздельные скетчи под протоколы NEC и RC5
