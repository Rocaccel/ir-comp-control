# **IR comp control**

**Русский** | [English](README.en.md)

**IR comp control** — легковесная утилита для Windows на языке Go, превращающая обычный ИК-пульт в полноценный контроллер компьютера. Пульт → ИК-приёмник → Arduino → COM-порт → программа: эмуляция клавиатуры, умная мышь с ускорением, медиа-команды и безопасное выключение ПК — всё это работает из системного трея, без лишних окон.

## Обзор

Программа состоит из двух частей:

- **Прошивка для Arduino** (`for_arduino_controller/IR-controler-dual.ino`) — принимает сигналы от ИК-приёмника и передаёт коды кнопок в последовательный порт. Поддерживает протоколы **NEC** и **RC5** одновременно с автоматическим определением.
- **Приложение для Windows** (`src_golang/`) — читает коды из COM-порта и выполняет действия: эмуляцию клавиш, движение мыши, системные команды.

Обе части общаются по простому текстовому протоколу: каждая строка — код кнопки в формате `NEC_XX` или `RC5_XX` (шестнадцатеричный номер команды).

## Как это работает

```
┌──────────┐   ИК-сигнал   ┌──────────────┐   Serial    ┌─────────────────┐   WinAPI   ┌──────────┐
│ ИК-пульт │ ───────────→ │ ИК-приёмник  │ ──────────→ │ Arduino Uno     │ ─────────→ │ Go-       │ ──→ Клавиатура / Мышь / Система
│          │              │ (D2, 5V, GND)│  115200     │ (скетч dual)    │  COM-порт  │ приложение│
└──────────┘              └──────────────┘             └─────────────────┘            └──────────┘
```

1. **Пульт** отправляет ИК-сигнал (протокол NEC или RC5).
2. **ИК-приёмник** (например, TSOP4838, VS1838B) демодулирует сигнал и отдаёт его на пин **D2** Arduino.
3. **Скетч** `IR-controler-dual.ino` (библиотека IRremote) декодирует сигнал, автоматически определяет протокол и печатает в Serial строку вида `NEC_36` или `RC5_36`.
4. **Go-приложение** читает строки из COM-порта, ищет код в таблице `config.toml` и выполняет связанное действие через WinAPI.

## Возможности

| Возможность | Описание |
| :---- | :---- |
| **Эмуляция клавиатуры** | Буквы A–Z, цифры 0–9, F1–F12, навигация (стрелки, Home/End, PgUp/PgDn, Insert/Delete), медиа-клавиши (громкость, play/pause, следующий/предыдущий трек, стоп) |
| **Умная мышь** | Перемещение курсора кнопками пульта с логарифмическим ускорением: чем дольше держишь — тем быстрее летит |
| **Безопасное выключение** | Таймер на 10 секунд с отменой любой кнопкой пульта или закрытием окна |
| **Работа в трее** | Иконка в системном трее: статус, перезагрузка конфига, открытие настроек, режим отладки, выход |
| **Автоопределение протокола** | NEC и RC5 работают одновременно, переключение не нужно |
| **Режим отладки** | Показывает сырые коды от пульта для привязки кнопок |
| **Zero-GUI** | Нет окна консоли при работе (собирается с `-H=windowsgui`) |
| **Один экземпляр** | Мьютекс не даёт запустить программу дважды |

## Технологии

**Приложение (Windows):**

- **Язык:** Go 1.26+
- **systray** — иконка и меню в системном трее
- **micmonay/keybd_event** — эмуляция нажатий клавиш
- **tarm/serial** — чтение COM-порта
- **BurntSushi/toml** — разбор конфигурации
- **golang.org/x/sys/windows** — типизированные обёртки WinAPI
- **WinAPI (user32/kernel32)** — курсор, мышь, сообщения, мьютекс

**Прошивка (Arduino):**

- **Arduino Uno** (и совместимые на ATmega328P)
- **IRremote 4.5.0** — декодирование ИК-протоколов (NEC, RC5 и др.)

## Требования

**Аппаратные:**

- Плата Arduino Uno или совместимая (ATmega328P)
- ИК-приёмник с тремя выводами (TSOP4838, VS1838B и аналоги)
- ИК-пульт с протоколом NEC или RC5 (подойдут почти любые бытовые пульты)
- USB-кабель для подключения Arduino к компьютеру

**Программные:**

- Windows (7/10/11)
- Arduino IDE (для прошивки скетча)
- Go 1.26+ (только если собираешь из исходников)

## Быстрый старт

### 1. Подключение ИК-приёмника к Arduino

| Вывод приёмника | Куда подключить |
| :---- | :---- |
| OUT (сигнал) | D2 |
| VCC (питание) | 5V |
| GND (земля) | GND |

Скетч ждёт сигнал именно на пине **D2**. Перед подключением сверьтесь с распиновкой вашего конкретного приёмника — расположение ног у разных моделей отличается. Питания от USB достаточно, внешний блок не нужен.

### 2. Установка библиотеки IRremote

1. Откройте Arduino IDE.
2. Перейдите в *Инструменты → Управлять библиотеками…* (или `Ctrl+Shift+I`).
3. Найдите **IRremote** и установите версию **4.5.0** (или новее).

### 3. Прошивка скетча

1. Откройте `for_arduino_controller/IR-controler-dual.ino` в Arduino IDE.
2. Выберите плату: *Инструменты → Плата → Arduino Uno*.
3. Выберите порт: *Инструменты → Порт → COMx* (ваш Arduino).
4. Нажмите *Загрузку* (стрелка вправо).

### 4. Проверка приёма

1. Откройте *Монитор порта* (лупа в правом верхнем углу) на скорости **115200**.
2. Направьте пульт на приёмник и нажимайте кнопки.
3. Должны приходить строки вида `NEC_36` или `RC5_36` — префикс зависит от протокола пульта.

> При старте скетч печатает служебную строку `Arduino IR to Serial Bridge Ready (NEC + RC5 auto-detect)` — программа её молча пропускает, это нормально.

### 5. Запуск программы

1. Запустите `ir-comp-control_v0.1.0-win64.exe`.
2. При первом запуске рядом с exe создастся `config.toml` — откройте его и проверьте параметр `port` (должен совпадать с портом Arduino, например `"COM4"`).
3. Программа сворачивается в трей. Нажимайте кнопки пульта — действия выполняются.

> **Важно:** перед запуском программы закройте Монитор порта Arduino IDE — иначе порт будет занят.

## Настройка (config.toml)

Файл конфигурации создаётся автоматически при первом запуске. Формат — TOML.

### Основные параметры

| Параметр | Описание | Пример |
| :---- | :---- | :---- |
| `port` | Имя COM-порта, к которому подключён Arduino | `"COM4"` |
| `baud` | Скорость передачи (должна совпадать со скоростью в скетче) | `115200` |

### Секция `[buttons]`

Сопоставляет коды кнопок пульта и действия в системе. Коды выводятся с префиксом протокола (`NEC_` или `RC5_`), который определяется автоматически.

```toml
[buttons]
"NEC_36" = "SYSTEM_SHUTDOWN"   # Кнопка питания → выключение ПК
"NEC_B"  = "VK_SPACE"         # Эмуляция пробела
"NEC_12" = "VK_VOLUME_UP"     # Громкость +
"NEC_13" = "VK_VOLUME_DOWN"   # Громкость −
"NEC_3D" = "MOUSE_UP"         # Движение мыши вверх
```

### Доступные команды

| Категория | Команды |
| :---- | :---- |
| **Системные** | `SYSTEM_SHUTDOWN`, `WIN_D`, `ALT_TAB`, `ALT_F4` |
| **Мышь** | `MOUSE_UP`, `MOUSE_DOWN`, `MOUSE_LEFT`, `MOUSE_RIGHT`, `L_CLICK` |
| **Медиа** | `VK_VOLUME_UP`, `VK_VOLUME_DOWN`, `VK_VOLUME_MUTE`, `VK_PLAY_PAUSE`, `VK_NEXT`, `VK_PREV`, `VK_STOP` |
| **Навигация** | `VK_LEFT`, `VK_RIGHT`, `VK_UP`, `VK_DOWN`, `VK_PAGEUP`, `VK_PAGEDOWN`, `VK_HOME`, `VK_END`, `VK_INSERT`, `VK_DELETE` |
| **Основные** | `VK_SPACE`, `VK_ENTER`, `VK_ESC`, `VK_BACKSPACE`, `VK_TAB`, `VK_CAPSLOCK` |
| **Цифры** | `VK_0` … `VK_9` |
| **Буквы** | `VK_A` … `VK_Z` |
| **Функциональные** | `VK_F1` … `VK_F12` |
| **Прочее** | `VK_PRINT`, `VK_PAUSE` |

## Важно о конфиге и миграция

Конфигурационный файл **вшит в exe** через `go:embed` и распаковывается при первом запуске — **только если рядом с программой нет файла `config.toml`**.

> ⚠️ Существующий файл `config.toml` **никогда не перезаписывается**. Если вы обновили exe, а рядом лежит старый конфиг — программа продолжит использовать старый файл.

**Миграция со старых версий:** после прошивки dual-скетча коды кнопок изменились с `KEY_xx` на `NEC_xx` / `RC5_xx`. Если у вас остался старый конфиг:

- **Вариант 1:** удалить `config.toml` — при следующем запуске создастся новый из вшитого шаблона.
- **Вариант 2:** вручную заменить префикс `KEY_` на `NEC_` (или `RC5_`) во всех строках секции `[buttons]`.

## Как работают функции

### Ускорение мыши

Программа использует адаптивный алгоритм перемещения курсора:

- **Базовый шаг:** 10 пикселей за одно нажатие.
- **Ускорение:** начиная с 4-го подряд нажатия, шаг растёт по формуле `10 + 60 · ln(1 + (n − 3))`, где `n` — число накопленных сигналов.
- **Сброс:** счётчик сбрасывается при паузе дольше 160 мс или смене направления.

### Алгоритм выключения

1. При получении команды `SYSTEM_SHUTDOWN` проигрывается системный звук.
2. Появляется окно с 10-секундным обратным отсчетом.
3. **Для отмены:**
   - Нажмите **любую** кнопку на ИК-пульте.
   - Или закройте окно на экране.
4. При отмене прозвучит мягкий сигнал, таймер останавливается.

### Дебаунс

Клавиатурные и системные команды имеют дебаунс 150 мс — случайные повторы при удержании кнопки отфильтровываются. Движение мыши и клики выполняются без дебаунса для плавного перемещения.

## Режим отладки

Если кнопки пульта не реагируют:

1. Включите **«Режим отладки»** в меню в трее (галочка).
2. Нажимайте кнопки на пульте — программа будет показывать окна с полученными кодами (например, `Получен: NEC_A1` или `Получен: RC5_A1`).
3. Скопируйте код и добавьте его в секцию `[buttons]` файла `config.toml`.
4. Нажмите **«Перезагрузить конфиг»** в меню трея — изменения применятся без перезапуска.

## Сборка из исходников

Требования: Windows, Go 1.26+.

Все зависимости подтянутся автоматически через `go mod tidy`.

```cmd
cd src_golang
go mod tidy
go build -trimpath -ldflags "-s -w -H=windowsgui" -o ..\ir-comp-control_v0.1.0-win64.exe .
```

Флаги сборки:

| Флаг | Назначение |
| :---- | :---- |
| `-trimpath` | Убирает абсолютные пути из бинарника |
| `-s -w` | Отладочная информация и таблица символов удаляются (меньше размер) |
| `-H=windowsgui` | Сборка без окна консоли |

> **Про иконку exe:** файл `rsrc_windows_amd64.syso` содержит ресурсы иконки для Проводника — **не удаляйте его**, иначе собранный exe будет без иконки. Если меняли `icon.ico`, перегенерируйте ресурсы:
>
> ```cmd
> rsrc -ico icon.ico -o rsrc_windows_amd64.syso
> ```

## Устранение неполадок

| Проблема | Решение |
| :---- | :---- |
| **«Не удалось открыть COM-порт»** | Закройте Монитор порта Arduino IDE — порт занят. Проверьте, что плата подключена и драйвер установлен. |
| **Кнопки не реагируют** | Включите режим отладки и проверьте, какие коды приходят. Убедитесь, что префикс в `config.toml` (`NEC_`/`RC5_`) совпадает с реальным. |
| **Тишина в Мониторе порта** | Проверьте подключение приёмника (D2/5V/GND), батарейки в пульте, направьте пульт прямо на приёмник. |
| **Мышь дёргается** | Это нормально при первых нажатиях — ускорение растёт с 4-го повтора. При паузе дольше 160 мс скорость сбрасывается. |
| **Выключение не отменяется** | Отмена работает любой кнопкой пульта или закрытием окна. Убедитесь, что скетч шлёт коды (проверьте Монитором порта). |
| **Программа не запускается** | Возможно, уже запущен другой экземпляр (мьютекс). Проверьте трей и Диспетчер задач. |
