# **IR comp control**

**Русский** | [English](README.en.md)

Легковесная утилита для Windows на Go, превращающая ИК-пульт в контроллер компьютера: эмуляция клавиатуры, умная мышь с логарифмическим ускорением, медиа-команды и безопасное выключение ПК. Работает из системного трея без окон.

---

## Архитектура

```
ИК-пульт → ИК-приёмник (D2, 5V, GND, 115200) → Arduino Uno (IRremote) → COM-порт → Go-приложение → WinAPI
```

Скетч `for_arduino_controller/IR-controler-dual.ino` декодирует NEC/RC5 и печатает строки вида `NEC_36` или `RC5_36`. Приложение сопоставляет коды с `config.toml` и эмулирует действия.

---

## Возможности

| Возможность | Описание |
| :--- | :--- |
| **Эмуляция клавиатуры** | A–Z, 0–9, F1–F12, навигация, медиа-клавиши |
| **Умная мышь** | Перемещение с логарифмическим ускорением, сброс при паузе >160 мс |
| **Безопасное выключение** | 10-секундный таймер с отменой любой кнопкой |
| **Работа в трее** | Статус, перезагрузка конфига, отладка, выход |
| **Мультипротокол** | NEC и RC5 одновременно |
| **Zero-GUI, один экземпляр** | Сборка `-H=windowsgui`, мьютекс |

## Быстрый старт

**Подключение приёмника:** OUT → D2, VCC → 5V, GND → GND.

**Прошивка:**
1. Установить библиотеку IRremote в Arduino IDE.
2. Открыть `for_arduino_controller/IR-controler-dual.ino`, выбрать плату и порт, загрузить.
3. В Мониторе порта 115200 проверить строки `NEC_XX`/`RC5_XX`. Закрыть монитор перед запуском.

**Запуск:**
1. Запустить `ir-comp-control_v0.1.0-win64.exe`.
2. При первом запуске создастся `config.toml` рядом с exe — проверьте `port`.
3. Меню в трее: Перезагрузить конфиг, Открыть конфиг, Режим отладки.

---

## Настройка `config.toml`

```
port = "COM4"
baud = 115200

[buttons]
"NEC_36" = "SYSTEM_SHUTDOWN"
"NEC_B"  = "VK_SPACE"
"NEC_12" = "VK_VOLUME_UP"
"NEC_3D" = "MOUSE_UP"
```

Доступно: `SYSTEM_SHUTDOWN`, `WIN_D`, `ALT_TAB`, `ALT_F4`, `MOUSE_UP/DOWN/LEFT/RIGHT`, `L_CLICK`, медиа `VK_VOLUME_*`, `VK_PLAY_PAUSE`/`NEXT`/`PREV`/`STOP`, навигация, `VK_SPACE`/`ENTER`/`ESC`/`BACKSPACE`/`TAB`/`CAPSLOCK`, цифры, буквы, `VK_F1`-`F12`, `VK_PRINT`, `VK_PAUSE`.

> Конфиг встроен через `go:embed` и распаковывается только при отсутствии файла рядом с exe. Существующий `config.toml` никогда не перезаписывается.

## Как работают функции

**Ускорение мыши:** базовый шаг 10 px. С 4-го последовательного нажатия шаг растёт `10 + 60·ln(1 + (n-3))`. Сброс при паузе >160 мс или смене направления.

**Выключение:** системный звук, окно с обратным отсчётом 10 с. Отмена любой кнопкой пульта или закрытием окна.

**Дебаунс:** 150 мс для всех действий, кроме движения мыши.

---

## Режим отладки

Включить чекбокс «Режим отладки» в трее. При нажатии кнопок приложение показывает окна с кодами `NEC_XX`/`RC5_XX`. Скопируйте код в `[buttons]`, нажмите «Перезагрузить конфиг».

## Сборка

```cmd
cd src_golang
go mod tidy
go build -trimpath -ldflags "-s -w -H=windowsgui" -o ..\ir-comp-control_v0.1.0-win64.exe .
```

`rsrc_windows_amd64.syso` содержит иконку exe. При изменении `icon.ico`: `rsrc -ico icon.ico -o rsrc_windows_amd64.syso`.

---

## Устранение неполадок

* **COM-порт занят** — закрыть Монитор порта Arduino IDE.
* **Кнопки не реагируют** — проверить префикс `NEC_`/`RC5_` в `config.toml`, включить отладку.
* **Тишина в мониторе** — проверить D2/5V/GND, батарейки, направление пульта.
* **Мышь дёргается** — нормально на первых нажатиях, ускорение растёт с 4-го.
* **Программа не запускается** — уже запущен второй экземпляр, проверьте трей.
